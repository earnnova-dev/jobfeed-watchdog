10 free public JSON APIs you can monitor — no auth, live today

Every endpoint below is free, requires no API key, and returns a list of records — the exact shape jobfeed-watchdog watches. Each row ships the endpoint, the record_path to the list, and a ready-to-paste config so you can catch a silent schema change, record-count collapse, or outage the moment it happens. (All 10 were verified live & key-free on 2026-10-01.)

Pick one and start watching in 30 seconds

Why these 10

Most "API listicles" are stale and full of endpoints that need a key, a rate-limited tier, or a dead redirect. This list is the opposite: each endpoint was called and checked this month — it returned HTTP 200 with a real list, with zero authentication, so a monitor has nothing to configure beyond the URL. If any of them break or change shape, jobfeed-watchdog turns your build red — which is exactly what it is built to do.

Use them as a canary set: point a monitor at a couple of the most critical feeds you actually consume, and the rest become a cheap "is the internet still normal" tripwire. Because the core is stdlib-only and runs as a GitHub Action, monitoring any of these costs nothing.

Start watching one in 30 seconds

Clone the action, drop in a feeds.json, and you're done. Here's the exact config for the first entry on the list — it's the feed this tool was built for:

{
  "feeds": [
    {
      "id": "remote-jobs-api",
      "url": "https://remote-jobs-api.tten.no/v1/jobs",
      "record_path": "jobs",
      "count_ratio": 0.5,
      "min_count": 5,
      "timeout": 30
    }
  ]
}

Then monitor any other endpoint from the table by adding the same shape with its URL and record_path. Want to watch the HN and weather feeds at once?

{
  "feeds": [
    { "id": "hn-ai", "url": "https://hn.algolia.com/api/v1/search?query=ai", "record_path": "hits", "min_count": 3 },
    { "id": "nyc-weather", "url": "https://api.open-meteo.com/v1/forecast?latitude=40.7&longitude=-74.0", "record_path": "daily.temperature_2m_max", "min_count": 1 }
  ]
}

Run it on a schedule (the action defaults to every 6 hours) and GitHub pages you via your normal Actions notifications when a feed's shape or count regresses. The whole setup is in the repo README — no server, no secrets, no billing.

Fair-use notes

  • All of these are public, no-auth endpoints as of 2026-10-01. Some (GitHub, CoinGecko) have rate limits on their free tiers — a 6-hourly monitor stays well inside them; don't hammer them per-minute.
  • If an endpoint's shape is nested deeper, set record_path to the dotted path of the list (e.g. query.search for Wikipedia).
  • These are third-party services. This page is a convenience reference — check each service's terms if you build on top of them commercially.
